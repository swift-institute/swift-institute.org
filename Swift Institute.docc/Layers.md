The ecosystem spans four layers. Each builds only on layers below. Every package targets Swift 6.4 and the version 27 Apple platforms.

| Layer | Organization | Question answered |
|-------|--------------|-------------------|
| 1. Atoms | [swift-atoms](https://github.com/swift-atoms) | What must exist? |
| 2. Molecules | [swift-molecules](https://github.com/swift-molecules) | What is built from atoms? |
| 3. Standards | [swift-standards](https://github.com/swift-standards) and the per-authority organizations | What is specified externally? |
| 4. Compositions | [swift-compositions](https://github.com/swift-compositions) | What can be composed? |
